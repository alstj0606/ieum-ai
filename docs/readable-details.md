# 대안 선택과 상세 카드 가독성 (2026-11-10)

## 화면 변경

- 대안 선택은 `슬로우조깅 정보 보기 →`처럼 동작이 드러나는 문구와 Streamlit 기본 primary 버튼을 사용한다. 어두운 파랑(#124d78)/흰색, 굵은 글씨, 64px 이상 높이, 버튼 아래 12px 여백을 적용했다. 색상 외에도 활동명·동작·화살표가 표시된다.
- 선택한 대안의 결과가 있으면 해당 답변은 안내 문장보다 공식 카드가 먼저 나온다. 그 답변에서 대안 목록·일반 아이디어·기존 실패 문구를 반복하지 않는다. 정보가 실제로 없으면 기존 대체 안내를 유지한다.
- 과거 대화는 삭제하지 않는다. 카드 ID를 기준으로 현재 답변 내 중복을 제거한다. 과거 답변에 있던 카드를 새 요청에서 다시 확인하는 것은 대화 기록 보존 범위이며 전체 기록을 임의 삭제하지 않는다.
- 프로그램명과 접수 상태를 먼저 보여준다. 참가 비용, 모집 대상, 지역, 장소, 상세 주소, 운영 시간, 접수 기간, 다음 접수 예정일, 신청 방법, 준비물은 기본 화면에 표시한다. 값은 굵게 구분한다.
- 확인일·정확한 접수 시각·긴 주의사항·공식 출처는 ‘주의사항·공식 출처’에 모았다. 공식 URL과 확인된 전화 링크, 신청 안내 기능은 유지한다. 마감·미확인 참고 카드에는 신청 안내 버튼을 제공하지 않는다.

## 날짜와 정보 경계

`registration_display`는 기존 JSON의 접수 일시를 한국 시간으로 바꿔 `2026.08.18 ~ 08.21`로 표시한다. 연도가 바뀌면 종료 연도도 표시한다. 정확한 시작/마감 시각은 별도 항목에 둬 매일 그 시간에 접수한다는 의미로 오해하지 않도록 한다.

모집 상태는 기존 `availability_status`를 그대로 사용한다. 실제 한국 시간 기준으로 접수 예정·마감·활동 종료를 계산하지만, 원문 상태가 closed/unknown이면 기간만 보고 접수중으로 승격하지 않는다. 실시간 잔여석을 확인한 상태가 아니다.

‘다음 접수 예정일’은 현재 공식 접수 기간의 시작일이 아직 미래이고 기존 상태 판단도 upcoming인 경우에만 그 날짜를 보여준다. 이는 이미 공지된 접수 시작일이며 새로운 회차를 추정한 것이 아니다. 그 외에는 ‘다음 접수 일정 미정’이다. 과거 접수 기간을 반복 일정으로 환산하거나 내년/다음 달 날짜를 생성하지 않는다. 현재 자료에 별도의 다음 회차 일정은 구조화되어 있지 않다.

비용 null과 무료 0은 구분한다. 확인되지 않은 비용·주소·대상·준비물·신청 방법은 ‘공식 자료 확인 필요’로 표시한다. 준비물은 기존 verification_notes에 ‘준비 안내.’로 명확히 기록된 항목만 그대로 추출한다. 개화산 숲체험의 긴팔·긴바지·운동화·마실 물은 이 기존 확인 기록에 근거하며 나머지는 확인 필요로 둔다. 공식 자료 10건과 출처·확인일을 변경하지 않았다.

## 렌더링과 호환성

선택 직후 기존 최신 답변 앵커를 카드 앞에 둔다. 긴 카드의 높이가 바뀌어도 최대 2.5초 동안 ResizeObserver와 제한된 재시도로 위치를 보정한다. 새 클릭·키 입력·휠/터치 등 사용자 조작이 생기면 보정을 취소한다. 지속적인 강제 스크롤은 하지 않는다.

마이크·전송 UI와 기존 음성 기능 코드는 유지했다. 새 스타일은 `st-key-alternative_` 키 클래스의 버튼만 지정하며 새 패키지를 추가하지 않았다. 스크롤은 기존 Streamlit `data-testid`와 JS 삽입 방식에 의존한다. Streamlit 버전 변경 시 DOM/스타일 및 스크롤 테스트를 다시 해야 한다. 검사는 현재 설치된 Streamlit 1.66.1에서 수행한다.
