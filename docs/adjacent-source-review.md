# 인접 지역 공식 자료 검토 (2026-11-10)

추가한 운영 데이터는 **0건**이다. 기존 강서구 공식 10건과 확인일은 변경하지 않았다. 검색 결과 요약만으로 프로그램이나 모집 상태를 추가하지 않았다.

| 공식 출처 | 실제 확인 범위 | 반영 여부 |
| --- | --- | --- |
| [양천구시설관리공단 회원모집](https://www.ycs.or.kr/fmcs/100) | 목록에서 11월 초 공고와 성인 소그룹 수영 초급 공고를 확인 | 개별 공고의 접수 기간/현재 모집 상태를 함께 검증하지 못해 제외 |
| [목동문화체육센터 성인 소그룹 수영 공고 상세](https://www.ycs.or.kr/fmcs/100?action=read&action-value=85c5db5d346de15fd06fece08f75c86b) | 공식 목록에서 상세 링크를 열었으나 조회 도구에서 TimeoutError | 상세 본문 접근 실패. 프로그램 세부 정보를 검증했다고 표현하지 않음 |
| [신월문화체육센터 프로그램 안내](https://www.ycs.or.kr/fmcs/23) | 2026년 11월 월별 안내와 일반 접수 방식·프로그램 표를 확인 | 개별 수업의 현재 모집 여부/잔여석을 확인하지 못해 제외. 강서구 걷기 강좌의 실제 대체 프로그램으로 임의 분류하지 않음 |

공식 사이트를 개발 조사 과정에서 확인한 것이며, 앱이 이 사이트들을 실시간 검색하거나 잔여석을 조회하는 기능을 구현한 것은 아니다. 외부 검색 API·비용·패키지는 추가하지 않았다. 이번에는 검증이 부족한 자료를 넣기보다 ‘현재 확인된 인접 지역 프로그램 자료가 없습니다’라는 제한을 정확하게 표시한다.
