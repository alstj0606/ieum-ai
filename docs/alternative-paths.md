# 대안 활동과 지역 확대 (2026-11-10)

## 구현 흐름

1. 요청 지역·활동의 정확한 결과를 기존 `recommend`로 확인한다. 접수 가능 표시도 잔여석을 보장하지 않는다.
2. 정확한 신청 가능 결과가 없으면 `services/alternative_paths.py`의 명시적인 활동 관계표에서 같은 지역 대안을 찾는다. 신청 가능 표시 대안을 먼저, 마감·미확인 대안을 다음에 보여준다. 각 대안은 실제 JSON 프로그램명과 접수 상태를 미리 보여주며 선택 후 전체 공식 카드로 이어진다.
3. 정확한 활동의 참고 카드도 유지한다. 종료·접수 미확인 자료에는 기존 경고가 표시되고 신청 안내 버튼이 없다.
4. 인접 지역은 사용자가 ‘네’ 또는 명확한 동의 버튼을 누른 뒤에만 저장된 공식 자료를 조회한다. 동의 전에는 인접 지역 레코드가 있어도 결과에 포함되지 않는다. 원래 지역 조건은 보존하며 확대 결과에는 해당 프로그램의 실제 지역·주소를 표시한다.
5. 거절하면 같은 지역만 유지한다. 동의했어도 자료가 없으면 ‘검증된 자료가 아직 없음’을 설명하며 일반 아이디어와 같은 지역 대안을 남긴다. 실시간 검색 결과처럼 표현하지 않는다.

대안 버튼은 활동 종류·카테고리·이전 관심 태그만 정리하고, 지역·시간·예산·나이·초보 여부·참여 목적·이동 선호를 유지한다. 초보 학습 조건에 맞지 않는 시설 이용을 대안으로 몰래 통과시키지 않는다. 비용 단위를 비교할 수 없으면 참고 결과로만 제공한다.

## 추천 근거와 한계

관계표는 프로그램 사실 DB가 아닌 편집된 비교 규칙이다. 걷기→체조는 몸을 움직이는 목적, 걷기→슬로우조깅/파크골프는 야외 활동이라는 공통점을 설명한다. 슬로우조깅은 걷기보다 부담이 클 수 있음을, 파크골프는 교육·장비·이동 편의 확인이 필요함을 안내한다. 수영→아쿠아로빅도 수영 입문 수업과 다름을 명시한다.

실제 운동 강도·경사·교통·휠체어 접근성은 기존 공식 자료에서 구조적으로 검증되지 않았다. 따라서 ‘가벼운 운동에 적합’, ‘가까움’, ‘이동이 편함’처럼 확정하거나 나이로 건강·이동 능력을 추론하지 않는다. 관계표 순서와 접수 상태로 우선순위를 정하며 실제 강도/거리 점수나 의료 적합성 점수는 만들지 않는다. 조건에 맞는 대안이 없으면 일반 아이디어로 이어진다. 일반 아이디어는 실제 모집 프로그램과 별도 제목을 사용한다.

## 데이터 확장 계약

현재 `data/activities.json` 10건과 기존 조사 기록은 변경하지 않았다. 공식 사이트의 추가 자료를 이번 환경에서 검증하지 못했으므로 다른 지역 프로그램을 추가하지 않았다. 확인일도 기존 2026-11-09를 그대로 보존한다.

기존 레코드의 `region`에 `서울특별시 양천구` 등 실제 소재지를 기록하고, `facility_name`, `address`, `target`, `schedule`, `fee_amount`(0≠null), `registration_period`, `registration_method`, `source_url`, `official_url`, `verified_at`, `registration_status`를 동일하게 검증해 추가할 수 있다. 확인되지 않은 값은 null로 남긴다. 참여 자격 규칙이 필요한 새 자료는 `recommendations.RULES`도 공식 원문에 맞춰 검토해야 한다.

`local_rows`는 서울 자치구 단위로 정확히 범위를 나누며 부산 강서구와 혼동하지 않는다. 인접 관계는 `NEIGHBOURS`의 명시적 등록표다. 현재 강서구에서 양천구·마포구로의 확대와 일부 역방향만 정의했다. 서울 전체·경기도·거리 기반의 자동 확대는 지원하지 않는다. 추가 지역은 소재지/인접 관계와 공식 출처를 사람이 검토해야 한다.

현재 인접 지역 데이터가 0건이므로 동의 버튼은 **조회 범위 동의와 데이터 부족 안내까지** 작동한다. 실제 인접 지역 프로그램을 제공한다고 주장하지 않는다. 인접 지역 결과·신청 재검증 로직은 테스트 전용 레코드로 검증하며 가상 레코드는 운영 JSON에 저장하지 않는다. 인접 조회는 현재 같은 활동의 결과/참고 자료를 반환하며, 인접 지역의 유사 활동 추천까지 자동 확대하지 않는다.

## 표시와 공식 경로

공식 카드의 상세 정보에 지역과 접수 기간을 추가했다. 시설명·주소·대상·비용·일정·신청 방법·공식 출처·확인일은 기존 데이터만 표시한다. 일반 아이디어에는 공식 사실을 덧붙이지 않는다.

‘공식 페이지에서 직접 더 찾아보기’는 이미 보유한 자료의 공식 URL을 여는 보조 경로다. 새 검색 API·스크래핑·자동 웹 탐색을 도입하지 않았다. 해당 사이트의 다른 모집 공고를 사용자가 직접 확인하도록 안내한다. 기관 전체 검색 결과나 잔여석을 조회한 것으로 표현하지 않는다.
